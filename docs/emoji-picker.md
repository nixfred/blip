# Composer emoji picker

Choose the smiley beside Send, search by Unicode name or category, then click an emoji or use Down and Enter. Exact pasted emoji are available too. Insertion replaces the current selection and returns focus to the composer without sending. Escape closes the popup; drafts stay in memory.

The Unicode catalogue and licence are included. No Mac tool, permission or bridge setting is added. Run `bun test` and `python3 scripts/test-composer-emoji-ui.py`.
